## Bug yang sudah diperbaiki selama verifikasi

- Livewire/Alpine dimuat dua kali → pencarian dan pagination tidak berfungsi.
- Pencarian form peminjaman memakai `wire:model.debounce` tanpa `.live` → hasil tidak muncul.
- Pengembalian parsial menimpa `qty_returned` (bukan akumulatif) → pinjaman tidak pernah selesai.
- Tombol pengembalian tidak pernah tampil karena memakai flag `canAct` yang khusus status pending.
- Status `APPROVED` tidak memiliki aksi serah terima → alur berhenti sebelum `DIPINJAM`.
- Stok parsial rusak/hilang mengubah status seluruh baris barang.
- File bukti/BA/BAST dapat diakses langsung dari URL publik.
- Selector JavaScript label massal salah (`item_ids` vs `item_ids[]`) dan atribut Alpine tidak valid.
- `/logout` melalui GET tidak tersedia (memang harus POST).
- Route closure menghalangi `route:cache`.
